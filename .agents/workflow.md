# Workflow

- Use Conventional Commits when committing, with subject lines no longer than 90 characters.
- Run `npm run lint` before `npm run build`; resolve warnings and errors before considering the work complete.
- Keep changes scoped to the requested task and existing ownership boundaries.
- Do not revert uncommitted user changes unless the user explicitly asks.
- Update [docs/refactoring-plan.md](../docs/refactoring-plan.md) when a plan item changes status.
- Put durable implementation plans under [docs/plans/](../docs/plans/).
