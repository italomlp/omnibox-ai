# OmniBox AI 0.1.0-alpha.1

Release preparation for the static web app and a separate Capacitor Android alpha. The web target is [italomlp.github.io/omnibox-ai](https://italomlp.github.io/omnibox-ai/); the Android application ID is `com.italomlp.omniboxai`.

**Status: alpha candidate. Live provider inference is NOT LIVE-VERIFIED.** This document does not certify a deployed site, Play upload, signed artifact, real-device install, or provider response. Attach the artifact manifest and verification evidence to the eventual release before making those claims.

## Included

- A browser workbench for grammar/tone, career documents, regex, schema translation, TypeScript/JSDoc, and browser speech, with local Library records.
- User-configured provider routes and local inference options on supported web browsers.
- A static [privacy page](https://italomlp.github.io/omnibox-ai/privacy.html) describing local records, BYOK credentials, cloud requests, and browser speech.
- Push/PR CI and a separate manual Pages workflow that validates a full commit SHA, requires it to belong to `main` history, checks out that exact source, reruns verification, and builds for `/omnibox-ai/`.
- A deterministic SHA-256 artifact manifest tool, a release runbook, and draft Play materials. Optional CLI upload tooling targets an internal **draft** release only.

## Web and Android differences

| Capability | Web | Android alpha |
| --- | --- | --- |
| Provider keys | Persist in browser localStorage | Memory for the current app session |
| Documents and run records | Browser IndexedDB | Device-local web storage |
| Cloud routes | User-selected, subject to CORS and Privacy Mode | User-selected, subject to platform/provider restrictions and Privacy Mode |
| WebLLM/WebGPU | Supported browsers; explicit model downloads | Disabled |
| Ollama | Configured local endpoint, subject to browser restrictions | Disabled |
| Speech | Browser/OS-dependent; recognition blocked in Privacy Mode | Disabled |

## Known limitations and evidence boundary

- **NOT LIVE-VERIFIED:** real cloud inference, actual local model downloads/inference, and browser speech. Providers can reject CORS, model IDs, permissions, quotas, or requests. Automated mocks do not establish successful live responses.
- Signed APK/AAB signatures and metadata passed verification; emulator scenarios and exact hashes are recorded in the handoff and manifest. Physical-phone behavior, Play account eligibility, review and upload acceptance remain unverified. No Play upload is claimed here.
- Web keys and workspace records are not encrypted by the app. Clearing a Library collection does not clear settings or all legacy records. Clearing app/site storage can remove local work; maintain your own backups.
- WebGPU/model compatibility, memory, storage eviction, and browser speech vary by device. The current web build includes large JavaScript and WASM assets and reports a chunk-size warning.
- Compatible dependency updates removed high-severity advisories. Three moderate advisories remain in Mammoth's Node CLI dependency chain, outside the browser execution path; no breaking downgrade was applied.
- No analytics or ad integration is included. This does not mean third-party provider or hosting traffic is absent; see the privacy page.
