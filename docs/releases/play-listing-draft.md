## Short description

AI productivity tools with your own provider keys and a local workspace.

## Full description

OmniBox AI brings focused writing and developer tools into a single productivity workspace.

Review grammar and tone, work with career documents, explore regular expressions, translate schema definitions, and draft TypeScript or JSDoc. Keep document text, run history, and generated artifacts in a local Library on your device.

Connect a supported AI provider using your own API key. Provider accounts, network access, charges, usage limits, and terms may apply. Entered task content is sent to the provider you choose when using cloud inference. Privacy Mode blocks cloud inference and cloud fallback.

The Android alpha keeps API keys in memory for the current app session. Keys must be entered again after the app process restarts. WebLLM/WebGPU, Ollama, and speech features are disabled in this Android alpha. Workspace records remain in device-local storage and are not a guaranteed backup.

This is an early alpha for feedback. Live provider inference is NOT LIVE-VERIFIED for this release, generated results may be incomplete or incorrect, and browser or device capabilities can vary. Review outputs before using them and keep backups of important work. The app includes no advertising or analytics integration.
