Privacy

OmniBox AI · 0.1.0-alpha.1 · Updated October 20, 2026

OmniBox AI is a client-side productivity app. Its web interface runs in your browser; the Android alpha packages the interface on your device. There is no OmniBox AI account or application backend receiving your workspace records.

Records stored on your device

The app uses IndexedDB (the OmniBoxDB database) to keep imported or pasted document text, run inputs and outputs, generated artifacts, provider and model identifiers, timestamps, errors, and legacy history. These records can contain personal or sensitive information you choose to enter. Settings and some temporary reload inputs are stored in localStorage.

In the web app, the provider API keys you enter are saved in localStorage under the app's browser origin, together with preferences. They are not encrypted by the app. Other people or software with access to that browser profile may be able to read them. Use a private device, restrict provider keys where possible, and remove keys in Settings when finished.

In the Android alpha, API keys are kept in memory for the current app session rather than persisted by the app. You need to enter them again after the app process restarts. Other workspace records still use device-local web storage; this is not a secure vault or a guaranteed backup.

Requests to providers you select

If you select a cloud provider or allow cloud fallback, the app sends the input needed for that task (which may include document text and context), your selected model, and your API credential directly to the configured provider endpoint. The default cloud endpoints use HTTPS; if you configure a custom endpoint, verify its security and operator before using it. Available provider routes include OpenAI, Google Gemini, OpenRouter, and Anthropic-compatible endpoints. A custom endpoint or proxy you configure also receives these requests. Each recipient applies its own retention, processing, billing, and privacy terms; review those terms before sending sensitive content.

Web Ollama connects to the local endpoint you configure. A custom remote URL is not guaranteed to stay on your device. Browser CORS and HTTPS mixed-content rules can block access to a local server.

Privacy Mode and local models

Privacy Mode blocks the app's cloud inference routes and cloud fallback. Browser speech recognition is disabled in Privacy Mode because it is not verified to run locally. The setting does not erase existing records, revoke provider keys, or undo requests already sent.

WebLLM inference runs locally using WebGPU on supported web browsers. Loading an uncached model requires an explicit model load or download action and network downloads of model weights and runtime assets from the model hosts. Model downloads are separate from sending your task inputs to a cloud inference provider. Cached models may use substantial device storage. Clear browser site data and model caches if you want to remove downloaded assets.

The app does not embed analytics, advertising, third-party fonts, or CDN scripts. Loading the hosted site still contacts its hosting provider, which may process normal request information such as IP addresses and user agents. Your browser, operating system, extensions, and configured services may have their own network behavior.

Browser speech

On the web, speech recognition requires your action and microphone permission. Your browser or its vendor may process microphone audio using a network service; OmniBox AI does not verify that recognition stays on your device. Speech synthesis voices and processing depend on your browser and operating system. Transcript cleanup through an AI provider follows the provider and Privacy Mode settings above.

Deleting records

Library and History delete controls remove the records named by each control. Clearing one Library collection does not clear settings or all legacy history. To remove all local app data, use your browser's site-data controls to clear IndexedDB, localStorage, and caches for the app origin; on Android, use the app's storage controls or uninstall it. Deleting local records does not delete information already sent to a provider. Contact that provider about its deletion options.

Alpha limitations

Live provider inference is NOT LIVE-VERIFIED for this release. WebGPU, model downloads, browser speech, CORS, and storage durability vary by browser and device. The Android alpha disables WebLLM/WebGPU, Ollama, and speech features. Android keys are session-only. Store publication and production readiness are not implied by this privacy page.

Do not rely on generated output without reviewing it. Keep your own backups of important data. This page describes the intended alpha behavior; report any behavior that differs.
